Token Usage Analyzer - Getting Started Guide

Overview

The Token Usage Analyzer provides real-world usage data for your AI Agent to help you estimate costs for LLM (Large Language Model), STT (Speech-to-Text), and TTS (Text-to-Speech) services. This dashboard aggregates actual usage metrics from your Cognigy AI Agent to give you accurate insights for budgeting and cost planning.

Purpose

Use this tool to:

  • Understand actual usage patterns across different time periods
  • Estimate monthly/annual costs based on real usage data
  • Identify high-usage flows that drive the majority of costs
  • Track usage trends over time to forecast future expenses
  • Make informed decisions about service tiers and pricing plans

How to Use the Dashboard

Step 1: Select Your Date Range

  1. Navigate to the "Date Range Selection" section at the top of the dashboard
  2. Select your From Date - the start of the period you want to analyze
  3. Select your To Date - the end of the period you want to analyze
  4. Click "Fetch Token Data" to retrieve and analyze usage data

Best Practices:

  • Start with a recent 7-30 day period to understand current usage patterns
  • Use monthly periods (e.g., first day to last day of a month) for monthly cost estimation
  • Compare different time periods to identify trends and seasonal variations

Step 2: Review Your Usage Metrics

Once the data loads, you'll see comprehensive usage statistics organized into several sections:

Understanding Your Usage Data

LLM Usage Metrics

What it measures: The amount of AI processing (token consumption) your AI Agent performed.

Key Metrics:

  • Total LLM Input Tokens: Total tokens consumed from user inputs and context
  • Total LLM Output Tokens: Total tokens generated in AI responses
  • Total LLM Tokens: Combined input and output token usage
  • Average LLM Tokens/Session: Average token consumption per conversation
  • Avg LLM Tokens/Turn: Average token consumption per interaction

Cost Estimation: Multiply total tokens by your LLM provider's per-token pricing to estimate costs. For example:

• If you used 1,000,000 tokens and your provider charges $0.002 per 1,000 tokens

• Estimated cost: 1,000,000 ÷ 1,000 × $0.002 = $2.00

STT/TTS Usage Metrics

What it measures: Speech-to-Text (listening) and Text-to-Speech (speaking) usage.

STT Metrics:

  • Total STT: Overall speech-to-text usage
  • Deepgram STT (minutes): Total minutes of audio processed (Deepgram bills per minute)

TTS Metrics:

  • Total TTS: Overall text-to-speech usage
  • ElevenLabs TTS (characters): Total characters converted to speech (ElevenLabs bills per character)

Cost Estimation:

• STT: Multiply total minutes by your STT provider's per-minute rate

• TTS: Multiply total characters by your TTS provider's per-character rate

Session & Turn Metrics

What it measures: Conversation volume and engagement patterns.

Key Metrics:

  • Total Sessions: Number of unique conversations/interactions
  • Total Conversation Turns: Total number of question-answer exchanges
  • Avg Turns/Session: Average number of interactions per conversation

Business Value: Helps you understand user engagement levels, conversation complexity, peak usage periods, and resource requirements.

Flow-Based Analysis

Token Usage by Flow Chart

A visual breakdown showing which parts of your AI Agent consume the most resources:

  • Blue bars: LLM token usage per flow
  • Cyan bars: STT usage per flow
  • Purple bars: TTS usage per flow

Use this to:

  • Identify high-cost flows that may need optimization
  • Understand which features drive the most usage
  • Prioritize cost optimization efforts

Token Usage Table

Detailed metrics for each flow/component of your AI Agent:

Columns Explained:

  • Flow Name: The specific component or conversation flow
  • LLM Input/Output/Total: Token usage breakdown for that flow
  • STT Tokens: Speech-to-text usage for that flow
  • TTS Tokens: Text-to-speech usage for that flow
  • Sessions: Number of conversations using that flow
  • Total Turns: Number of interactions in that flow
  • Avg Turns/Session: Average interactions per conversation
  • Avg LLM/STT/TTS per Session: Average resource consumption per conversation

Use this to: Calculate per-flow costs, identify optimization opportunities, and understand resource distribution across your AI Agent.

Cost Estimation Workflow

1. Gather Usage Data

  • Select a representative time period (e.g., one month)
  • Fetch and review the usage metrics

2. Calculate Base Costs

  • LLM Costs: Total tokens × provider rate per token
  • STT Costs: Total minutes × provider rate per minute
  • TTS Costs: Total characters × provider rate per character

3. Project to Longer Periods

  • Monthly Projection: Use a full month's data
  • Annual Projection: Multiply monthly by 12 (adjust for seasonality if applicable)
  • Growth Projection: Factor in expected usage growth

4. Compare Scenarios

  • Run reports for different time periods
  • Compare peak vs. average usage
  • Model different growth scenarios

Tips for Accurate Cost Estimation

  1. Use Representative Periods: Select time periods that reflect typical usage patterns
  2. Account for Growth: If usage is trending upward, factor that into projections
  3. Consider Seasonality: Some businesses have seasonal variations in usage
  4. Review Flow-Level Data: High-cost flows may need optimization before scaling
  5. Regular Monitoring: Run reports monthly to track trends and adjust projections

Interpreting the Results

High Usage Indicators

  • High token counts: Complex conversations or large context windows
  • High STT minutes: Voice-heavy interactions
  • High TTS characters: Verbose responses or frequent voice output

Optimization Opportunities

  • Flows with high per-session averages may benefit from optimization
  • Compare average usage across flows to identify outliers
  • Review flows with high token-to-turn ratios (may indicate inefficiency)

Troubleshooting

No data appears:

  • Verify your date range includes periods with actual usage
  • Ensure both From Date and To Date are selected
  • Check that the date range is valid (From Date before To Date)

Unexpectedly low or high numbers:

  • Verify the date range covers the intended period
  • Check for data gaps or incomplete periods
  • Compare with previous periods to identify anomalies

Next Steps

  1. Baseline Current Usage: Run a report for the most recent complete month
  2. Calculate Current Costs: Apply your provider rates to the usage metrics
  3. Project Future Costs: Extrapolate based on growth expectations
  4. Identify Optimization Targets: Review flow-level data for cost reduction opportunities
  5. Set Up Regular Reviews: Schedule monthly reviews to track trends

For questions about interpreting the data or calculating costs, refer to your LLM, STT, and TTS provider documentation for current pricing rates and billing models.
