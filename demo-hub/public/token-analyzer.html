Configure API keys for Deepgram and ElevenLabs token usage data. Calls are proxied through the server to avoid CORS issues.

Use a per-flow API key for accurate tracking.
Azure STT/TTS: Enable if using Azure Speech Services. Azure usage is read from Analytics custom fields (custom4 = STT hours, custom5 = TTS characters).

OData Connection

Connect to Cognigy OData API to get session and flow information. LLM tokens are stored in custom OData fields via the Overwrite Analytics node.

How to store LLM tokens: Place an Overwrite Analytics node just above the "End" node. Set custom1=inputTokens, custom2=outputTokens, custom3=totalTokens using {{input.aiAgentOutput.tokenUsage.*}}.
